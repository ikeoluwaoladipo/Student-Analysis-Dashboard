

# Student Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed for **EduPro Learning Academy**, an education organization.

The dashboard analyzes student academic performance, teacher information, and fee payment data to help the organization understand performance patterns, identify areas requiring attention, and support data-informed decision-making.

## Business Problem

An education organization needs a clear way to monitor student performance, understand teacher effectiveness, and track fee payments.

When these areas are viewed separately in raw tables, it can be difficult to identify patterns, compare performance, and quickly recognize areas that may require intervention.

This project brings the available data into an interactive dashboard to provide a clearer view of the organization's academic and financial information.

## Project Objectives

The objectives of the project were to:

- Analyze student academic performance.
- Identify performance patterns across students, levels, and subjects.
- Examine teacher effectiveness and experience.
- Monitor fee payments and outstanding fees.
- Present key information through interactive Power BI dashboards.
- Provide insights that can support better decision-making.

## Dataset

The project contains three main datasets:

### Students

The Students dataset contains information about:

- Student ID
- Name
- Gender
- Age Group
- Level
- Course
- Score

### Teachers

The Teachers dataset contains:

- Teacher ID
- Name
- Subject Taught
- Years of Experience
- Qualification

### Fees

The Fees dataset contains:

- Student ID
- Term
- Total Fee
- Amount Paid
- Payment Status

## Data Preparation

The data was prepared before analysis to improve consistency and usability.

Key preparation activities included:

- Reviewing the structure of the datasets.
- Cleaning and standardizing data.
- Checking for blanks and missing values.
- Preparing fields for analysis.
- Creating appropriate relationships between datasets.
- Creating calculated measures for key financial and performance metrics.

## Key Performance Measures

Some of the measures used in the analysis include:

- Total Fees Paid
- Outstanding Fees
- Student Performance Categories
- Student Performance by Level
- Student Performance by Subject
- Teacher Effectiveness
- Student Counts

### Performance Categories

Student scores were grouped into four performance categories:

| Score Range | Category |
|---|---|
| 80 and above | Excellent |
| 60–79 | Good |
| 40–59 | Average |
| Below 40 | Needs Improvement |

## Dashboard Analysis

The dashboard provides different views of the education data, including:

### Student Analysis

The student analysis focuses on academic performance and allows performance to be explored across different levels and subjects.

### Teacher Analysis

The teacher analysis provides information that can be used to examine teacher experience, qualifications, subjects taught, and effectiveness.

### Fees Analysis

The fees analysis provides visibility into:

- Total fees
- Amount paid
- Outstanding fees
- Payment status
- Fee information across student levels and terms

## Key Insights

The dashboard was designed to help identify:

- Differences in student performance across levels and subjects.
- Students or performance groups that may require additional academic support.
- Patterns that can be explored when assessing teacher effectiveness.
- The level of fees collected compared with outstanding amounts.
- Areas where management may need further investigation.

## Recommendations

Based on the analysis, the organization can use the dashboard to:

- Monitor students who may require additional academic support.
- Investigate subjects or levels with weaker performance.
- Use teacher performance information alongside experience and qualification data when planning support and development.
- Monitor outstanding fees regularly.
- Follow up on overdue or pending payments.
- Use the dashboard as a regular reporting tool for management decisions.
